# Parche de audio (F9-a)
1. Copia las carpetas de este zip dentro de tu proyecto (donde está `index.html`), combinando carpetas. No se sobrescribe nada tuyo.
2. En esa carpeta: `node tools/apply-audio.mjs`  (hace 4 ediciones mínimas y se puede repetir sin duplicar).
3. `npm run check` y `npm test` (debe terminar con «Todas las pruebas de audio pasaron»).
4. `npm start` y abre http://localhost:5173/?dev=1 · y para escuchar todo: http://localhost:5173/audio-lab.html
Guía para conectar el combate: docs/INTEGRACION-AUDIO.md
